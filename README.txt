Обновление существующего проекта Vercel

1. Распакуй архив.
2. На странице проекта habbits-six в Vercel открой Deployments.
3. Загрузи содержимое распакованной папки как новый deployment.
4. После публикации открой сайт и обнови страницу.
5. Если старая версия осталась на iPhone, полностью закрой приложение и открой снова.

Важно: localStorage сохраняется только если адрес сайта остаётся тем же.
